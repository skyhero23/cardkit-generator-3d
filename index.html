Despliegue en GitHub Pages

Publica tu generador gratis y en minutos con 0 configuración de servidor.

1 Crea un repositorio en GitHub

Entra en tu cuenta de GitHub y crea un nuevo repositorio público (ej: cardkit-generator-3d).

2 Sube los archivos del proyecto 
git init
git add .
git commit -m "Initial CardKit 3D Studio"
git branch -M main
git remote add origin https://github.com/skyhero23/cardkit-generator-3d.git
git push -u origin main
3 Activa GitHub Pages en 1 Clic

En tu repositorio ve a Settings → Pages.
En Branch selecciona main y carpeta / (root), luego haz clic en Save.
¡Listo! Tu web estará disponible en https://skyhero23.github.io/cardkit-generator-3d.
